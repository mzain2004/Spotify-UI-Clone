## 🎯 About The Project

This project is a front-end clone of the popular music streaming platform **Spotify**. It recreates the sleek and modern user interface that Spotify is known for, focusing on responsive design and clean code architecture.

### ✨ Key Highlights

- 🎨 **Pixel-perfect design** - Faithful recreation of Spotify's UI
- 📱 **Responsive layout** - Works seamlessly across different screen sizes
- 🎵 **Interactive elements** - Functional music player controls
- ⚡ **Pure vanilla JavaScript** - No frameworks, just clean code

---

## 🚀 Features

- ✅ Modern and clean user interface
- ✅ Sidebar navigation with playlists
- ✅ Music player controls (play, pause, skip)
- ✅ Album artwork display
- ✅ Progress bar visualization
- ✅ Volume controls
- ✅ Responsive design for mobile and desktop
- ✅ Custom favicon

## 🏁 Getting Started

Follow these simple steps to get a local copy up and running:

### Prerequisites

You only need a modern web browser to run this project! 

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/mzain2004/Spotify-UI-Clone.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd Spotify-UI-Clone
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html in your preferred browser
   # Or use a local server (recommended):
   
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js http-server
   npx http-server
   ```

4. **Visit** `http://localhost:8000` in your browser
